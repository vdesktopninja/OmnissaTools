# LogScrub Releases

This folder contains pre-built MSI installers for LogScrub.

## Current Release

### LogScrub v1.0.0.0
**File**: `LogScrub-Setup-v1.0.0.0.msi`
**Size**: ~45 MB (includes .NET 8 runtime)
**Publisher**: Dominik Jakubowski
**Target**: Windows 10/11 (x64)

#### Features:
- Complete self-contained installation
- No .NET runtime dependency
- Desktop and Start Menu shortcuts
- Uninstall support
- Material Design UI
- Multi-language support (English, Polish)

#### Installation:
1. Download `LogScrub-Setup-v1.0.0.0.msi`
2. Right-click → "Run as administrator"
3. Follow the installation wizard
4. Launch from Start Menu or Desktop shortcut

#### System Requirements:
- Windows 10 version 1909 or later
- Windows 11 (any version)
- 100 MB free disk space
- Administrator rights for installation

#### Digital Signature:
This MSI is digitally signed by Dominik Jakubowski for authenticity and security.
